# منظومة متابعة ومعالجة النقاط الحرجة - مصنع الغزال
## خطة مدير المصنع وموازنة 2027

منظومة تفاعلية متكاملة لمتابعة تنفيذ خطة معالجة الملاحظات الـ 34 الحرجة، وتوزيع المهام على الأقسام، وإدارة طلبات الشراء، وحسابات الموازنة الرأسمالية لعام 2027.

### هيكل الصلاحيات والحسابات:
- المهندس فادي محمود (مصمم المنظومة / Super Admin)
- المدير التنفيذي (CEO)
- مدير المصنع
- قسم الجودة
- قسم الصيانة
- قسم الإنتاج
- قسم المستودعات
- قسم المشتريات
- قسم المالية

### تشغيل المشروع على GitHub Pages:
1. فك ضغط الملفات.
2. ارفع ملف `index.html` و `README.md` إلى مستودع GitHub الخاص بك.
3. توجه إلى Settings -> Pages -> اختر Branch: `main` واضغط Save.
